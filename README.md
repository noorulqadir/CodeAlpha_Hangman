# CodeAlpha_HangmanGame

A simple text-based Hangman game built for the **CodeAlpha Python Programming Internship (Task 1)**.

## Features
- Picks a random word from a list of 5 predefined words
- Maximum of 6 incorrect guesses
- Input validation (single letters only, no repeated guesses)
- Replay option

## Concepts Used
`random`, `while` loop, `if-else`, strings, lists

## How to Run
```bash
python hangman.py
```
Requires Python 3.6+. No external libraries needed.
